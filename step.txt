# Step-by-Step Guide: How to Connect PocketBase to this Project

---

## Step 1: Download & Run PocketBase Server (Local Setup)

1. **Download PocketBase**:
   - Go to [pocketbase.io](https://pocketbase.io) and download the zip file for your OS (Windows x64 / macOS / Linux).
2. **Extract the Executable**:
   - Extract the downloaded `.zip` file into a folder (e.g., `C:\pocketbase` or inside your project folder).
3. **Start the PocketBase Server**:
   - Open Command Prompt or Terminal in that folder.
   - Run the command:
     ```bash
     `./pocketbase serve``
     ```
   - Server starts by default at: `http://127.0.0.1:8090`
4. **Create Superadmin Account**:
   - Open your browser and go to: `http://127.0.0.1:8090/_/`
   - Create your first Admin Email & Password when prompted.

---

> **IMPORTANT**: Raw SQLite `CREATE TABLE` queries do NOT automatically appear in the PocketBase Admin sidebar because PocketBase requires collections to be registered in its internal `_collections` schema system.
> **You MUST create collections using the PocketBase Admin UI (`+ New collection`) as shown below to get REST API access.**

---

## Step 2: Create Collections using PocketBase Admin UI (Required)

Click **`+ New collection`** on the left sidebar (as shown in your screenshot):

### Collection 1: `practices`
1. Click **`+ New collection`**
2. Collection Name: `practices` (Type: Base)
3. Click **`+ Add field`** to add:
   - `date` -> **Plain text**
   - `speakingTopic` -> **Plain text**
   - `chatgptPrompt` -> **Plain text**
   - `listeningTitle` -> **Plain text**
   - `listeningInstruction` -> **Plain text**
   - `listeningUrl` -> **Plain text / URL**
4. Click API Rules (lock icon tab) -> Unlock rules so API requests work.
5. Click **Create** / **Save**.

3. Click **`+ Add field`** to add:

   - `speakingTimestamp` -> **Plain text**

## Step 5: Connecting PocketBase in JavaScript Code

### 1. Initialize PocketBase instance:
```javascript
const pb = new PocketBase(POCKETBASE_URL);
```

### 2. User Authentication (Login):
```javascript
async function loginUser(usernameOrEmail, password) {
  try {
    const authData = await pb.collection('users').authWithPassword(usernameOrEmail, password);
    console.log('Logged in user:', authData.record);
    return authData;
  } catch (error) {
    console.error('Login failed:', error);
  }
}
```

### 3. Fetching Records:
```javascript
// Fetch today's practice content
async function getTodayPractice(dateStr) {
  try {
    const record = await pb.collection('practices').getFirstListItem(`date="${dateStr}"`);
    return record;
  } catch (error) {
    console.log('No practice found for date:', dateStr);
  }
}
```

### 4. Creating / Updating Records:
```javascript
// Create or Update Daily Log
async function saveDailyLog(logData) {
  try {
    // Check if record exists
    const existing = await pb.collection('logs').getFirstListItem(`studentId="${logData.studentId}" && date="${logData.date}"`).catch(() => null);
    if (existing) {
      return await pb.collection('logs').update(existing.id, logData);
    } else {
      return await pb.collection('logs').create(logData);
    }
  } catch (error) {
    console.error('Error saving log:', error);
  }
}
```

## Step 6: Deploying PocketBase to Cloud / Online Access

> [!WARNING]
> **PocketHost Update**: PocketHost now requires a paid subscription to run instances ("*Error: Instances will not run until you upgrade*").

Here are the best **FREE alternatives** to host or access your PocketBase server online:

---

### Option A: Local PocketBase + Free HTTPS Tunnel (Easiest for Demos & Testing)

Keep PocketBase running on your computer (`./pocketbase serve` at `http://127.0.0.1:8090`) and expose it securely to the internet with a free public URL:

#### Method 1: Using Built-in SSH Tunnel (No installation required)
Open a new terminal and run:
```powershell
ssh -R 80:localhost:8090 nokey@localhost.run
```
Copy the generated `https://xxxx.lhr.life` URL!

#### Method 2: Using `npx localtunnel` (Auto-accept prompt with `-y`)
Open a new terminal and run:
```powershell
npx -y localtunnel --port 8090
```
Copy the generated `https://xxxx.loca.lt` URL!

3. Update `POCKETBASE_URL` in [js/pocketbase-config.js](file:///d:/penmdrive/shbl/js/pocketbase-config.js):


8. Render will deploy PocketBase in ~1 minute.
9. **Your 24/7 Live URL** will be shown at the top:
   `https://shbl-spoken-english.onrender.com`
